# Order totals and stock are computed in Postgres, not in the app

Placing an Order runs as one Postgres function (`place_order`) called through Supabase RPC. In a single transaction it locks the Cart's Variants, checks Stock, decrements it, computes the Subtotal, Shipping Fee and Order Total in `numeric`, and writes the Order and Order Items. We chose this over computing totals in Dart for three reasons: a Customer must not be able to send their own prices, two Customers must not both buy the last unit, and a half-written Order must not exist. Cancellation (`cancel_order`) restores Stock the same way. The app only displays the numbers the database returns.
